# Calibration chain for run_nas_w39b.pbs (CALIBRATE_CHAIN=overrides/calibration_chain.txt).
# name|mode|overrides file|out dir|KEY=VAL;KEY=VAL   mode = probe (compile-only, cannot OOM) or calibrate
# Paths are relative to this case dir. Arms run in order; a failing arm is recorded, the rest run.
# The two probes report the peak buffer size at 576 particles; if either exceeds the card,
# the matching width arm below will OOM (only that arm fails). A MALA calibrate arm costs
# ~11 h (4.3 h init + two ~3 h sweeps at N=144; chains 78865/78867), so the full chain does
# NOT fit a 24 h wall: submit a subset, or use the fixed-step bench for profiling.
# nsys arms run LAST and capture the range the app marks around its timed sweep
# (NSYS_CAPTURE_API=1; a fixed window landed in the init on job 78814, and a windowed nsys
# orphaned its app and blocked every later arm). Read-outs: kernel count per step in the
# capture (LuPivotsToPermutation is 1:1 with getrf, the correct reading) and the
# no-command-buffer arm (an EMPTY --xla_gpu_enable_command_buffer= list; dropping the flag
# would only restore XLA's own default set) against the default (command buffers ON).
