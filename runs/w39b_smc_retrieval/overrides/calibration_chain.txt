# Calibration chain for run_nas_w39b.pbs (CALIBRATE_CHAIN=overrides/calibration_chain.txt).
# name|mode|overrides file|out dir|KEY=VAL;KEY=VAL   mode = probe (compile-only, cannot OOM) or calibrate
# Paths are relative to this case dir. Arms run in order; a failing arm is recorded, the rest run.
# The two probes report the peak buffer size at 576 particles; if either exceeds the card,
# the matching width arm below will OOM (only that arm fails). One arm costs the ~1 h cold
# init plus one sweep; the whole chain is about 10 h of a 24 h wall.
# nsys windows: the init takes ~55 min, so a 60 s window at 3600 s lands in the sweep; the
# kernel count per step in that window (LuPivotsToPermutation must be 0 on vulcan-jax 0.12.1)
# and the command-buffer arm's launch count are the read-outs besides t_mutation_sweep_s.
